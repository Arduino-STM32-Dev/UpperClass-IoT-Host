# HostListener — слушатель хоста верхнего уровня

TCP **сервер** на хосте верхнего уровня: принимает входящие соединения новых PCB по 4G / Ethernet, пишет сырые и кадрированные байты. Входит в частный репозиторий `UpperClass-IoT-Host`.

**Языки:** [中文](README.md) · [English](README.en.md) · [Русский](README.ru.md)

## Делает / не делает

| Делает | Не делает |
|---|---|
| Слушает `0.0.0.0:9800` (настраивается), много PCB | Полный архив, auth, Web UI |
| Печатает IP:порт пира и hex | Привязку к одному отраслевому имени |
| Режет кадры `80` / `86` + минимальный ACK | Полный GI / команды / БД |
| Порт из аргументов | Требование базы данных |

Роли: хост = TCP **сервер**; PCB = TCP **клиент** (после 4G — к `IP-хоста:9800`).

## Запуск

```bash
cd host-listener
dotnet run -- --port 9800
```

| Аргумент | По умолчанию | Смысл |
|---|---|---|
| `--port` | `9800` | Порт прослушивания |
| `--bind` | `0.0.0.0` | Адрес привязки |
| `--quiet-hex` | выкл. | Меньше сырых дампов |
| `--max-hex` | `256` | Макс. байт на кусок в логе |

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
publish\HostListener.exe --port 9800
```

## Лог

- `CONNECT` — PCB подключилась (часто 4G NAT IP)
- `RX` / `FRAME` — сырое / кадр
- `TX ACK` — минимальный ответ на fixed-кадры статуса канала
- `CLOSE` — отключение и счётчики

## Для лаборатории

1. Открыть входящий **TCP 9800**  
2. Запустить программу  
3. PCB или симулятор → `ip-хоста:9800`  
4. `CONNECT` + `RX`/`FRAME` = путь живой  

## Безопасность

Превью: **без TLS и auth**. Не выставлять в открытый Интернет без firewall / VPN / allow-list.
